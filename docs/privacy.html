Política de Privacidad

Última actualización: julio de 2026

YouTube Watchlist → Notion Scheduler ("la aplicación") es una herramienta de automatización de uso estrictamente personal, operada y usada únicamente por su desarrollador, Héctor Reyes, sobre su propia cuenta de Google/YouTube y su propio workspace de Notion. No está disponible para el público ni tiene otros usuarios. Esta página describe qué datos de Google accede la aplicación, con qué propósito, y cómo se tratan.

1. Qué datos se acceden

La aplicación usa la YouTube Data API v3, con el scope https://www.googleapis.com/auth/youtube.force-ssl, exclusivamente para:

  • Leer los videos guardados en una playlist privada llamada "Por ver": título, URL, duración e identificador del elemento de la playlist (playlist_item_id).
  • Eliminar de esa misma playlist los videos que ya fueron agendados exitosamente en el paso siguiente.

No se accede a ningún otro dato de la cuenta de Google del usuario (no se leen correos, contactos, archivos de Drive, ni ningún otro contenido de YouTube fuera de la playlist mencionada).

2. Qué se hace con esos datos

Por cada video leído, la aplicación crea un recordatorio equivalente (título, enlace al video y horario propuesto) en la base de Notion privada del propio desarrollador, evitando choques con su Google Calendar y con recordatorios ya existentes. Una vez agendado, el video se borra de la playlist de YouTube.

3. Dónde se almacenan los datos

La aplicación no mantiene una base de datos propia ni almacena copias de los datos de YouTube entre ejecuciones. En cada corrida, los datos se leen de la YouTube Data API, se transforman en memoria, y se escriben directamente en el workspace de Notion del propio usuario. Al terminar la ejecución, no queda ningún dato retenido por la aplicación.

4. Con quién se comparten los datos

Con nadie. Los datos no se venden, no se comparten con terceros, no se usan con fines publicitarios y no se usan para entrenar modelos de machine learning. El único destino de los datos es el propio workspace de Notion del usuario que autorizó el acceso.

5. Cumplimiento de la Política de Datos de Usuario de Google API Services

El uso que esta aplicación hace de los datos obtenidos a través de las APIs de Google cumple con la Google API Services User Data Policy, incluyendo los requisitos de Uso Limitado ("Limited Use").

6. Cómo revocar el acceso

El usuario puede revocar el acceso de esta aplicación a su cuenta de Google en cualquier momento desde myaccount.google.com/permissions.

7. Cambios a esta política

Si esta política cambia, se actualizará esta misma página con una nueva fecha de "última actualización".
